1st command once a student has commited a branch
Code:
        git fetch

2nd commad is to check the branches
code: 
        git branch

3rd switch to the branch
code:
        git switch student-0

4th if everything is ok
code:
        git switch main

5th now we merge 2 branches
code:
        git merge student-0

6th but the final code to internet
code: 
        git add .
        git commit -m 'Tell what you have changed'
        git push origin main

7th Tell the student to run the final command
code: 
        git pull
